# Project contents

The downloadable archive contains:

- complete React/Vite storefront source and the production `dist/` build;
- Three.js bottle, physical glass and liquid rendering, Anime.js scroll choreography, mist, films, HDR environment, posters, and localized catalog imagery;
- shop, cart, checkout, order tracking, customer account, MFA, and owner portal screens;
- Vercel Function router, Postgres entities/authentication schema, transactional commerce actions, and Vercel Blob uploads;
- the standalone reusable component demo and exported component package;
- pinned Open Generative AI prompt utilities and Freefield workflow bindings/manifests with their licenses;
- deployment, component, and offline media-pipeline documentation;
- lockfiles and all validation scripts.

The archive intentionally excludes `.git`, `node_modules`, local environment files, deployment-account metadata, logs, and credentials. Run `npm ci` to reproduce dependencies exactly. `.env.example` contains placeholders only.
